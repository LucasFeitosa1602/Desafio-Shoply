# 📊 Desafio de Análise de Dados - Shoply

Projeto desenvolvido como parte do **Desafio de Analista de Dados da Rocketseat**, aplicando técnicas de limpeza, transformação e análise exploratória de dados utilizando Python.

---

## 🎯 Objetivo

O desafio consiste em preparar uma base de dados para análises futuras, garantindo qualidade, consistência e geração de novas informações através de Feature Engineering.

---

## 🚀 Etapas do Projeto

### 📥 1. Entendimento dos Dados

- Exploração inicial
- Tipagem das colunas
- Estatísticas descritivas
- Identificação de inconsistências

---

### 🧹 2. Tratamento dos Dados

Foram realizados diversos tratamentos, incluindo:

- Conversão de tipos
- Tratamento de valores ausentes
- Remoção de duplicidades
- Correção de datas inválidas
- Validação das regras de negócio
- Correção de inconsistências entre pedidos e entregas

---

### ⚙️ 3. Feature Engineering

Criação de novas variáveis para enriquecer a análise, como:

- Total de pedidos por cliente
- Ticket médio
- Dias desde a última compra
- Frequência de compras
- Valor total gasto
- Segmentação de clientes

---

### 📈 4. Análise Exploratória (EDA)

Durante a análise foram avaliados indicadores como:

- Evolução de clientes ativos
- Evolução do número de pedidos
- Ticket Médio (AOV)
- Pedidos por cliente
